### 🛠️ 我在做什么

- **开源 Skill 系列 `achow-xxx-skill`**：把真实工作流沉淀成可复用的 Agent Skill
- **「新号做 X 的学习笔记」**：用自己账号的后台数据做成图文卡片，在 X 上连载
- **自动化**：报表、文档、日常杂事，能交给脚本和 agent 的就不手动

### 🧰 achow Skill 系列

| Skill | 做什么 | 状态 |
| --- | --- | --- |
